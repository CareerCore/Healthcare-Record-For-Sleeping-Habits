# 🌙 Digital Insomnia: Screen Habits & Sleep

## 📌 Project Overview

A healthcare organization requires a data-driven solution for assessing patients' sleeping habits within its Psychology Department as a preliminary step before consultation.

The objective of this project is to analyze patients' sleeping patterns, digital screen habits, and sleep-related behaviors to help the healthcare organization better understand patients' sleep habits before their psychological consultation.

This project uses **ETL (Extract, Transform, Load), Exploratory Data Analysis (EDA), and Data Visualization** techniques to process and analyze sleep-related data and identify meaningful patterns that may support the pre-consultation assessment process.

## 🎯 Business Requirement

The healthcare organization's Psychology Department needs a preliminary sleep assessment process to understand patients' sleeping habits before consultation.

The proposed data analytics solution aims to:

- Assess patients' sleeping habits and patterns.
- Analyze daily digital screen usage.
- Examine sleep duration and sleep quality.
- Identify potential relationships between screen habits and sleep behavior.
- Generate meaningful insights that can support healthcare professionals during initial patient assessments.

## 🎯 Project Objectives

- Understand sleeping patterns through data analysis.
- Explore the relationship between digital screen usage and sleep behavior.
- Identify trends and patterns associated with sleep-related issues.
- Transform raw healthcare-related data into structured and meaningful information.
- Provide visual insights that can assist the Psychology Department during the pre-consultation stage.

## 🔄 Project Workflow

### 1. ETL – Extract, Transform & Load
- Extract data from the source dataset.
- Inspect the dataset structure and variables.
- Clean and preprocess the data.
- Handle missing or inconsistent values where necessary.
- Prepare structured data for further analysis.

### 2. Exploratory Data Analysis (EDA)
- Analyze patients' sleeping habits.
- Examine daily screen time and digital usage patterns.
- Explore sleep duration and sleep quality.
- Identify patterns and relationships among sleep-related variables.
- Generate insights from the available data.

### 3. Data Visualization
- Visualize sleeping patterns and screen usage.
- Analyze trends in sleep duration and quality.
- Present relationships between digital habits and sleep behavior.
- Generate understandable visual insights for healthcare stakeholders.

## 🏥 Healthcare Business Value

This project is designed to support the Psychology Department by providing preliminary data-driven insights into patients' sleeping habits before consultation.

The analysis may help healthcare professionals:

- Better understand patients' sleep-related behaviors.
- Identify patterns that may require further discussion.
- Prepare more informed questions for initial consultations.
- Use structured data insights as an additional reference during patient assessments.

**Note:** This project is intended as a preliminary analytical support tool and is not a diagnostic system. Clinical decisions should remain with qualified healthcare professionals.
